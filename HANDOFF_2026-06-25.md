> I would update the brief with these exact additions:
> Pinned Project Strip
> Use a tall scroll section.
> Pin/sticky the background/content layer.
> Let project rectangles move independently over it.
> Offset them left / center / right, not all centered.
> Release the whole strip only after the last rectangle exits.
>
> Hero Foreground Object
> Do not use an unfinished construction image for hero.
> Best direction: finished exterior photo.
> Create two layers:background plate with the house/object removed or softened/inpainted
> transparent foreground cutout of the house/object
> Animate foreground subtly on scroll so it separates from the background, like the Digitalists girl/train-station effect.
> Interior can work too, but exterior is simpler and more OPC-clear.
>
> Color/Contrast Lock
> The current contrast choices are not approved.
> Next build should pause before styling and choose a calmer/luxury palette that still feels OPC, not harsh or random.
>
> Better Validation
> Current validate.js catches blank screens and console errors, but it cannot tell whether the motion is correct.
> Add motion checks: bounding boxes at scroll positions, sticky layer position, card offsets, release point, and side-by-side scroll montage.
>

> Rebuild the relationship, not the visual asset:same scroll logic
